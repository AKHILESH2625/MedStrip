Parts, Sensors & Microcontroller Pinout Specifications

Motors & Actuators Power: 5V DC
  • • X-Axis Stepper: NEMA 17 / 28BYJ-48 via A4988 driver (GPIO 18: STEP, GPIO 19: DIR).
  • • Z-Axis Pusher: MG90S Metal-Gear Micro Servo via PWM (GPIO 23).
  • • Gantry Rails: Dual 8mm stainless rods with T8 2mm-pitch lead screw.
Verification Sensors Dual Feedback
  • • Foil Trace Fracture: Matrix multiplexer on GPIO 32-35 (Hardware interrupt on pin fracture).
  • • Chute Drop Sensor: TCRT5000 Infrared Beam Break at chute exit (GPIO 25: DIGITAL IN).
  • • Gantry Home Switch: Mechanical limit switch (GPIO 26: PULL-UP).
Display & Telemetry Dual Channel
  • • OLED Display: 1.3" 128x64 I2C (GPIO 21: SDA, GPIO 22: SCL).
  • • Web App Link: Web Bluetooth API (GATT 0x180D) + MQTT over WebSockets.
  • • Status Alert: Active Piezo Buzzer (GPIO 27) & NeoPixel RGB (GPIO 4).
